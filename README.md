# Smart Campus IoT Security

A security architecture for a fictional smart-campus environment using connected sensors, access systems, environmental monitoring and cloud services.

## Architecture
```text
Sensors / Devices
       |
   IoT Gateway
       |
  Campus Network
       |
+------+------+
|             |
Edge        Security
Processing  Monitoring
|             |
+------+------+
       |
    Cloud Platform
```

## Example Devices
Temperature sensors, occupancy sensors, smart lighting, access-control devices and environmental sensors.

## Security Requirements
- Unique device credentials
- Secure firmware updates
- Network segmentation
- Encrypted communications
- Role-based access
- Logging and monitoring
- Data minimisation

## Threats
Compromised IoT device, default credentials, rogue device, network pivoting, data interception and firmware vulnerabilities.
